# AutoCare Project

A responsive auto-repair website concept inspired by the broad layout and service-oriented feel of the supplied reference: a dark image-led hero, service cards, shop introduction, trust/difference section, reviews area, appointment form, and footer.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, styling, and mobile breakpoints
- `script.js` — mobile navigation, footer year, and demo form behavior

## Before launch
- Replace the sample AutoCare name with the actual shop name and logo.
- Add the real address, phone, opening hours, services, and verified testimonials.
- Connect the appointment form to Formspree or another form endpoint. It currently does not transmit submissions.
- Check and approve image licensing; photos currently load from Unsplash URLs.
- Update SEO metadata and add an approved social sharing image.

This is an original concept, not a copy of Christian Brothers Automotive branding, wording, or proprietary assets.
