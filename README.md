# AutoCare Garage — Auto Repair Website Concept

This is a reference-led rebrand concept for a local auto repair shop. The homepage has been rebuilt to follow the **same broad page architecture and user flow** as the supplied Christian Brothers Automotive Westfield reference, using the AutoCare Garage brand, a different navy/green/orange palette, original copy, and non-branded photography.

## Files
- `index.html` — homepage, navigation, content sections, FAQs, appointments, and testimonials
- `styles.css` — site styling, responsive layouts, mega-menu, hover states, and transitions
- `script.js` — desktop/touch navigation, scroll reveals, two-step appointment form, and testimonial controls
- `service.html` — reusable service detail/catalog page
- `service.js` — content for individual services and the all-services catalog

## Reference-led structure and interactions
- Separate utility/contact row, location strip, main nav, and prominent quick-action links
- Large hover-triggered **Our Services** mega-menu with common services, a multi-column full service directory, and two promotional cards
- Matching large **About Us** mega-menu with common-service shortcuts and shop-related links
- Responsive mobile/click version of both mega-menus
- Main banner, introductory location content, hybrid/EV service section, concierge options, technician/team content, maintenance and inspections, community/quality section, FAQs, awards/credentials, amenities, why-choose-us cards, owner/team block, service links, appointment form, and testimonial carousel
- Service links open `service.html?service=...` and render the matching service text

## Before publishing
1. Replace AutoCare Garage name/mark with the actual business's approved brand identity.
2. Add the verified shop location, phone number, business hours, service area, actual owner/team details, and real staff photos.
3. Confirm any shuttle/concierge service, amenities, technicians' certifications, awards, warranty terms, offers, and available services. The page currently labels those areas as details to verify rather than claiming specific credentials.
4. Add verified reviews with permission. Current testimonial text is explicitly placeholder copy.
5. Connect the appointment form to a scheduling system or form endpoint. **The current form is a visual/interaction demo only; it does not transmit or store appointment requests.**
6. Review all imagery and external asset permissions, metadata, accessibility, and the deployed mobile layout.

The site borrows structural inspiration from the reference page but does not use the reference company's name, logo, text, owner identities, reviews, or branded photography.
